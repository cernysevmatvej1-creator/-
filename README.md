# Group — Мобильное приложение для групп и встреч

**Мобильный клиент на .NET MAUI** для создания групп, поиска, управления заявками и встречами.  
Работает в связке с **GroupApi** (ASP.NET Core).

---

## 📱 Что умеет приложение

- 🔍 **Поиск групп** — находите группы по интересам
- ➕ **Создание заявок** — создавайте встречи внутри группы
- 👥 **Просмотр групп** — детальная информация о группе
- 📋 **Список участников** — смотрите, кто состоит в группе
- 💬 **Чат** — общение внутри группы

---

## 🛠 Технологии

- **.NET MAUI** — кроссплатформенная разработка
- **C# + XAML** — язык и разметка
- **MVVM** — архитектурный паттерн
- **HTTPS-клиент** — запросы к backend API
- **Слоистая архитектура** — сервисы, репозитории, интерфейсы
